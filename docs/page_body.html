An intent can ask for a payment on a chain no bridge reaches. Farshore is the Open Intents Framework oracle for those chains: GenLayer validators look across, read the far chain's own public record, and when the payment is exactly what the order asked, the court writes the proof that releases the solver's pay.

The crossing
X

OIF already knows how to pay a solver once an oracle proves the fill. It does not know how to see a chain no messaging layer reaches. That is the only part Farshore adds.

1
Open

The user locks inputs in OIF's settler and asks: pay this amount, to this account, on that chain.

InputSettlerEscrow.open
2
Pay across

A solver pays on the far chain. The memo is a hash of the order and the solver itself.

memoFor(order, solver)
3
Claim

The solver tells the oracle which transaction filled the order. A hash, nothing else.

FarshoreOracle.claim
4
The light

Validators read that transaction from the chain's own API and agree, in code, on FILLED or NOT_FILLED.

Farshore.verify
5
Paid, or refunded

The court's call writes OIF's proof; the solver finalises. Unfilled orders refund after expiry.

finalise / refund

Sail one

Open an order. Fill it yourself. Watch the light decide.

You play the user with MetaMask on GenLayer Bradbury. Your browser plays the solver with a throwaway Stellar testnet key, funded by Stellar's friendbot. Pay in full, or short it and see the court refuse.

The voyage

Each step is a real transaction. Signing on GenLayer costs a little test GEN; the Stellar side costs nothing.

The proof

Every way across, on chain.

One script, scripts/prove.mjs: real orders on OIF's settler, real payments on Stellar testnet and Base Sepolia, real Internet Court rounds, balances counted to the unit.

Every shore

OIF's settler: the same code at the same address.

The settler on GenLayer Chain is rebuilt from OIF's source with OIF's exact compiler input and sent through the same deterministic deployment proxy, so it lands where OIF's own deployments are. scripts/verify_evm.mjs compares all four.
